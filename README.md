This is a make.fun entry: a haiku about debugging, in the classic 5-7-5 form. It is about the small horror of chasing a bug at night, only to find the problem has gone somewhere else.

## The haiku

```
three a.m. cursor—
blinking where the error was.
the error moved in
```

## How it works

The program (`main.ts`, Node 22) writes the haiku to `/output/entry.txt`.

```
node main.ts
```
